# Skyll

Skyll grades handwritten exam papers for schools in India. A class
administrator scans answer sheets with the Skyll Intake app; Skyll reads them,
builds a question-level rubric from the official answer key, grades each
answer with the evidence kept for review, and publishes reports to students,
teachers and parents.

This is the Skyll codebase as it ran in production before the NEAR Hackathon,
published as the baseline for the `hackathon-submission` tag. Internal
documentation, operations scripts and client names have been removed.
